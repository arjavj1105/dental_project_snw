# dental_project_snw
SmileCare - Multi-Page Dental Clinic Website
📋 Project Overview
A fully functional, responsive dental clinic website built with pure HTML, CSS, and JavaScript (no dependencies). The website features multiple interconnected pages with smooth navigation and interactive elements.

📁 File Structure
text
SmileCare-Website/
├── index.html              # Home/Landing page
├── services.html           # Services page (6 services)
├── tips.html              # Oral care tips page
├── faqs.html              # FAQs & Myths page
├── patient-portal.html    # Patient portal dashboard
├── booking.html           # Smart appointment booking
├── style.css              # Main stylesheet (all pages)
└── script.js              # JavaScript functionality
